## Connection lost

- If echo loses its connection to the local server, it now shows a message saying what happened and when it will retry, with a **Restart echo** button. This replaces the old error box.
- The conversation is hidden while the connection is down.

## Loading

- Spinners have been removed throughout the app.
- Views that are loading show a short message with a line under it.
- Parts of a panel, such as avatars, shared rooms, maps and link previews, show placeholder shapes while they load.
- The button for loading older messages shows a thin moving line while it works. Confirm buttons no longer turn into spinners.
- The typing indicator no longer has bouncing dots.
- With Reduce Motion on, placeholders don't animate. **Ignore reduce motion** turns the animation back on.

## Fixes

- Fixed caption text colour in light mode.

## Known issue

- Read receipts aren't always sent, so a room can stay unread after you've read it. Marking it read in another client clears it.
